\chapter*{Abstract}
\thispagestyle{empty}
This thesis develops and documents a Pakistan-adapted reinforcement learning workflow for long-horizon crop-management experimentation on top of the CyclesGym environment. The work begins from the original CyclesGym base repository and extends it through Pakistan crop-calendar alignment, Pakistan price localization, multi-nutrient fertilization support, hierarchical integration of yearly crop planning with within-season fertilization, and standardized reporting for thesis-grade evaluation. The implemented stack uses a Pakistan weather file, Pakistan soil profile, and yearly crop and nutrient price series reconstructed from official sources while keeping the active crop-planning setup on the working maize-soy configuration already wired into the repository.

The thesis adopts a bounded empirical scope. Irrigation control, rice-specific localization, and field validation remain future work, while empirical claims are restricted to the completed final campaign and its frozen reporting artifacts. The final evidence base consists of a canonical 113-run bundle set with 16 recovered replacements, including corrected guarded hierarchical reruns and recovered DQN ablations. A repo-level reporting builder converts that frozen artifact set into one authoritative dataset for run-level metrics, grouped summaries, inferential statistics, and artifact audits.

The main contribution is therefore twofold. First, the work transforms the original CyclesGym codebase into a localized, NPK-capable, hierarchically extensible research platform for Pakistan-relevant decision support. Second, it establishes a reproducible reporting workflow in which thesis tables, figures, and final claims are rebuilt from canonical versioned artifacts rather than from manual transcription. This structure supports stronger empirical discipline, clearer provenance, and more defensible scope control in simulator-based agricultural reinforcement learning.
