\chapter{Reproducibility and Build Notes}

\section{Canonical Rebuild Commands}

The final thesis workspace can be rebuilt from the repository root with the following command sequence:
\begin{verbatim}
python scripts\build_final_reports.py
python "Local Files and Folders\Thesis Main Working\scripts\build_assets.py"
powershell -ExecutionPolicy Bypass -File "Local Files and Folders\Thesis Main Working\build.ps1"
\end{verbatim}

The first command rebuilds the canonical reporting outputs under \texttt{artifacts/final\_successful\_runs/final\_113/reporting/}. The second regenerates the LaTeX tables and figures from those canonical outputs. The third command compiles the thesis PDF using the portable Tectonic binary stored under \texttt{.tools/tectonic/}.

\section{Frozen Evidence Principle}

The final thesis no longer treats provisional runner summaries as the primary evidence source. Instead, the frozen \texttt{final\_113} bundle set is the canonical empirical surface. This is important because it eliminates the ambiguity that would otherwise arise from mixing dry-run CSVs, historical audit summaries, recovered rerun exports, and thesis prose without a single canonical reporting layer.

\section{Recovered Rows and Provenance}

Canonicalization does not mean that every row was preserved from a single uninterrupted first-pass run. Sixteen rows are recovered replacements, including the corrected guarded hierarchical reruns and recovered DQN reruns. The key reproducibility decision is therefore not to hide that recovery, but to preserve it explicitly in the canonical reporting outputs so that the thesis and the repository tell the same story.

\section{Generated, Not Hand-Copied}

The thesis workspace follows a generated-not-hand-copied philosophy. Tables are emitted as standalone \texttt{.tex} snippets. Plots and diagrams are generated by Python scripts and stored under \texttt{figures/generated/}. The build script composes those generated artifacts with the chapter text. This does not make the thesis immune to error, but it materially reduces the risk of stale numbers, contradictory counts, and manually transcribed result drift.
