\section{Why Provenance and Schema Belong in the Thesis}

In this project, data provenance and output schema are not peripheral implementation details. They are part of the scientific contract of the thesis. A localized price-aware reward is only defensible if the reader can understand where the price series came from. A results table is only reproducible if the reader can understand which JSON or CSV fields it was derived from. Including this appendix makes those dependencies explicit and reduces the distance between the written document and the actual repository artifacts.
