\chapter{Reproducibility and Build Notes}

\section{Thesis Build Commands}

The LaTeX workspace can be rebuilt by running the following command from the repository root:
\begin{verbatim}
powershell -ExecutionPolicy Bypass -File .\Thesis Main Working\build.ps1
\end{verbatim}

This command regenerates all figures and tables from repository artifacts and then compiles the thesis using the portable Tectonic binary stored under \texttt{.tools/tectonic/}.

\section{Smoke-Run Script}

A smoke-run script has been included to launch a small set of real runs before the full broad campaign is started:
\begin{verbatim}
powershell -ExecutionPolicy Bypass -File .\Thesis Main Working\scripts\run_smoke_subset.ps1
\end{verbatim}

The script targets three representative cases: one fertilization PPO run, one crop-planning PPO run, and one hierarchical PPO run. The outputs are directed to \texttt{Thesis Main Working/notes/smoke\_runs/}.

\section{Why Smoke Runs Precede the Full Matrix}

The smoke stage is deliberately narrower than the full latest-NPK matrix. Its role is to verify that the major execution pathways are alive: environment creation, CYCLES invocation, summary-file writing, hierarchical report generation, and thesis-asset regeneration. This prevents the main experiment campaign from becoming an expensive debugging session. In a simulator-heavy RL repo, this staging discipline is part of the reproducibility methodology rather than an optional convenience.

\section{Why the Current Draft Keeps Chapter 6 Provisional}

The latest broad NPK matrix is the intended main evidence base for the thesis. Because that campaign has not completed at the time of this build, the present draft treats Chapter~6 as a constrained status-and-context chapter rather than as the final results chapter. This is a deliberate integrity control, not a missing feature.

\section{Administrative Metadata}

University-specific metadata, including title-page fields and signatory names, has been isolated in \texttt{frontmatter/metadata.tex}. This allows rapid correction of administrative details before final submission without editing the technical chapters.

\section{Rebuild Philosophy}

The thesis workspace follows a ``generated, not hand-copied'' philosophy. Tables are emitted as standalone \texttt{.tex} snippets. Plots and diagrams are generated by Python scripts and versioned as PDF assets. The build script composes these generated artifacts with the chapter text. This design does not make the thesis immune to error, but it materially reduces the risk of stale tables, inconsistent labels, and manually transcribed result drift.
