# Limitations

## Geographic Scope

This MVP is intentionally framed as a single Pakistan-context demo region with weather scenarios. It does not claim province-wide or district-wide calibration.

## Model Scope

- maize is the only full daily-support crop
- soybean is seasonal/reference only
- recommendations are simulator-backed, not live sensor-backed

## Product Scope

- no user accounts
- no cloud sync
- no voice input
- no province-specific agronomy rules
- no free-text agronomy chatbot

## Scientific Scope

- policy outputs are clamped by demo-safe guardrails before display
- displayed costs use repo price-series assumptions
- the app should be presented as decision support, not autonomous farm control
