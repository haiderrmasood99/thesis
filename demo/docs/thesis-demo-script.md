# Thesis Demo Script

## 5-Minute Flow

1. Open the frontend and say this is a local inference app, not a cloud service.
2. Show the farmer-friendly input flow:
   - maize
   - vegetative
   - 5 acres
   - 120000 PKR
   - balanced soil
   - moderate rain
   - uncertain weather
3. Press `Get advice`.
4. Explain the result in plain language:
   - this week action
   - next follow-up cards
   - remaining season estimate
   - baseline comparison
5. Open the evidence drawer and point to bundle metadata.
6. Switch to soybean and use `Soybean seasonal reference`.
7. State clearly that soybean is reference-only in this MVP.

## Thesis Positioning Line

“This app demonstrates how audited RL policies can be translated into a farmer-facing decision-support workflow with local cost guardrails, comparison against baseline practice, and explicit limitation notes.”
