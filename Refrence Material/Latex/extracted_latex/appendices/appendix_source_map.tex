\chapter{Source and Artifact Map}

This appendix summarizes the main source families that ground the thesis.
\begin{itemize}[leftmargin=1.2cm]
    \item Official formatting and university sources: the official NUST MS thesis template, NUST Students Hub, and SEECS downloads pages.
    \item Pakistan context and economics: Pakistan Economic Survey, FAOSTAT producer prices, NFDC fertilizer prices, PBS crop calendars, and KP maize guidance.
    \item Technical foundations: CyclesGym, CropGym, gym-DSSAT, the agricultural RL review, and supporting RL literature.
    \item Local artifact sources: repository change logs, experiment audits, runner summaries, and generated pricing data files.
\end{itemize}

The explicit purpose of this appendix is to document that the thesis is grounded both in external primary sources and in local implementation artifacts. The writing process therefore remains traceable even when the repository continues to evolve.

\section{How to Read the Source Map}

External sources justify context, methodology, and localization choices. Local artifacts justify claims about implementation state, experiment readiness, and reproducibility. Neither category can replace the other. This appendix is therefore intended as a quick reference for tracing any thesis claim back to either a cited source family or a versioned repository component.
